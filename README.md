# SPMK 업로더 다운로드

영상이나 사진 하나를 올리면 AI가 제목·설명·해시태그를 만들어 주고, YouTube·Facebook·Instagram·TikTok·Threads·네이버 블로그에 한 번에 올리는 Windows용 프로그램입니다.
내 컴퓨터에서 실행되며, 입력한 키와 토큰은 내 컴퓨터에만 저장됩니다.

## 받기

**[최신 버전 다운로드 →](https://github.com/geon9892-dev/spmk-uploader-release/releases/latest)**

릴리스 페이지의 `Assets`에서 `SPMK-Uploader-v버전.zip` 을 받으세요.

## 설치 (처음 한 번)

필요한 것: Windows 10/11, 인터넷 연결

1. zip을 `C:\Users\내이름\SPMK-Uploader` 같은 폴더에 압축을 풉니다. (바탕화면·OneDrive 폴더는 동기화 때문에 느려질 수 있어 피하세요)
2. **`1_설치.bat`** 을 더블클릭합니다. Node.js가 없으면 자동 설치할지 물어봅니다. 몇 분 걸립니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누르세요.
3. **`2_앱실행.bat`** (또는 시작 메뉴에서 "SPMK") 으로 실행하면 브라우저에 **처음 설정** 화면이 열립니다.

## 처음 설정 — 내 계정 연결

처음 설정 화면의 순서대로 진행합니다.

1. **AI 키**: Google AI Studio에서 Gemini API 키(무료)를 발급해 저장
2. **채널 연결**: 쓰려는 채널만 연결. 각 채널의 개발자 앱은 **본인 계정으로 직접** 만들어야 합니다 (설정 화면에 단계별 안내가 있습니다)
3. **설정 마치기**

다른 사람의 키·토큰을 받아서 쓰면 그 사람 계정으로 게시되니 꼭 본인 계정으로 연결하세요.

## 업데이트

새 버전이 나오면 앱 상단에 알림이 뜹니다. 새 zip을 기존 폴더에 덮어쓰고 **`1_설치.bat`** 을 다시 실행하면 됩니다. 내 설정과 작업 기록은 그대로 유지됩니다.

## 끄기

**`3_앱종료.bat`** 을 실행합니다. 브라우저를 닫아도 예약 업로드를 위해 앱은 계속 켜져 있습니다.
