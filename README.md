# SPMK 업로더 다운로드

영상이나 사진 하나를 올리면 AI가 제목·설명·해시태그를 만들어 주고, YouTube·Facebook·Instagram·TikTok·Threads·네이버 블로그에 한 번에 올리는 Windows 프로그램입니다.
입력한 키와 토큰은 내 컴퓨터에만 저장됩니다.

## 받기

**[최신 버전 다운로드 →](https://github.com/geon9892-dev/spmk-uploader-release/releases/latest)**

릴리스 페이지의 `Assets`에서 `SPMK-Uploader-Setup-버전.exe` 를 받으세요.

## 설치

필요한 것: Windows 10/11 (64비트)

1. 받은 **SPMK-Uploader-Setup-버전.exe** 를 실행합니다.
2. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누르세요. (코드 서명 인증서가 없어 처음 한 번 나오는 경고입니다)
3. 설치가 끝나면 바탕화면·시작 메뉴의 **SPMK 업로더** 로 실행합니다. 관리자 권한은 필요 없습니다.

## 처음 설정 — 내 계정 연결

처음 실행하면 **처음 설정** 화면이 열립니다.

1. **AI 키**: Google AI Studio에서 Gemini API 키(무료)를 발급해 저장
2. **채널 연결**: 쓰려는 채널만 연결. 각 채널의 개발자 앱은 **본인 계정으로 직접** 만들어야 합니다 (설정 화면에 단계별 안내가 있습니다). "연결하기"를 누르면 기본 브라우저에서 로그인 창이 열립니다.
3. **설정 마치기**

다른 사람의 키·토큰을 받아서 쓰면 그 사람 계정으로 게시되니 꼭 본인 계정으로 연결하세요.

## 사용 중에

- 창을 닫아도 작업 표시줄 오른쪽 아래 **알림 영역** 에서 계속 실행되어 예약 업로드가 진행됩니다. 완전히 끄려면 아이콘을 오른쪽 클릭 → **종료**.
- 알림 영역 메뉴에서 **Windows 시작 시 자동 실행** 을 켤 수 있습니다.
